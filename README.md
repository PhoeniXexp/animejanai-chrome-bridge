# AnimeJaNai Chrome Bridge

Расширение Chrome для открытия HLS-видео из браузера в AnimeJaNai на Windows. Выберите серию и озвучку на сайте, передайте поток в плеер и верните позицию в браузер после просмотра.

## Возможности

- Автоматическое обнаружение потоков на выбранных сайтах; iframe и CDN вручную указывать не нужно.
- Запуск с текущей позиции минус 5 секунд. Видео в браузере остаётся на паузе, в том числе при ошибке запуска.
- Возврат последней полученной позиции после закрытия mpvnet, без автоматического продолжения в браузере.
- Отдельный список потоков для каждой вкладки.

Поддержка ориентирована на Kodik и проверялась на AnimeGo. Работа с произвольными плеерами не гарантируется. Это отдельный проект интеграции, не часть AnimeJaNai.

## Установка

Нужны Windows x64, Chrome, установленный AnimeJaNai и .NET Framework 4.x с компилятором C#. Node.js требуется только для тестов.

### 1. AnimeJaNai

Скачайте Windows-сборку из [официальных релизов](https://github.com/the-database/mpv-AnimeJaNai/releases), установите её и проверьте воспроизведение через `mpvnet.exe`. Типовой путь:

```text
%LOCALAPPDATA%\Programs\mpv-AnimeJaNai\mpvnet.exe
```

`%LOCALAPPDATA%` относится к текущему пользователю Windows. Если плеер установлен в другом месте, укажите свой путь при установке моста.

### 2. Расширение и локальный хост

1. Сохраните проект в постоянную папку. Chrome загружает расширение непосредственно из неё.
2. Откройте `chrome://extensions`, включите **Режим разработчика** → **Загрузить распакованное расширение** и выберите папку `extension`.
3. Скопируйте ID установленного расширения и запустите `install.cmd` обычным пользователем, без повышения прав. Введите ID и путь к `mpvnet.exe`. Enter принимает предложенное значение; ID по умолчанию подходит только если совпадает с ID в вашем Chrome.
4. Откройте настройки расширения, вставьте адрес страницы или домен сайта, например `https://animego.online`, нажмите **Сохранить сайт** и предоставьте запрошенное разрешение.
5. Нажмите **Проверить подключение к плееру**. Для этой версии ожидается хост **0.5.0** с включённым запуском.
6. Запустите видео на сайте. Если оно уже играло до установки, перезапустите его для обнаружения потока.

Установщик собирает хост при отсутствии готового файла, регистрирует его для текущего пользователя и включает запуск. Настройки AnimeJaNai не меняются. Python, обычный mpv и другие расширения для передачи видео не требуются.

## Использование

1. Выберите серию и озвучку в плеере сайта и запустите видео.
2. Откройте расширение и нажмите **Открыть этот поток** возле нужной ссылки.
3. Продолжите просмотр в открывшемся отдельном экземпляре mpvnet.
4. Закройте mpvnet. Исходное видео в браузере перейдёт к последней полученной позиции и останется на паузе.

Оставьте исходную вкладку открытой. Возврат пропускается, если вы сменили серию, перезагрузили страницу, возобновили просмотр в браузере или открыли другой файл в mpv. Соединение ограничено шестью часами. Сохранение позиции для кнопки сайта «Продолжить» зависит от самого сайта.

| Кнопка | Когда нужна |
|---|---|
| **Открыть этот поток** | Передать выбранное видео в AnimeJaNai |
| **Обновить список** | Видео запущено, пока окно расширения уже открыто. При повторном открытии окна список загружается сам |
| **Настройки → Очистить список** | Удалить устаревшие ссылки; затем перезапустить видео для повторного обнаружения |
| **Проверить подключение к плееру** | Проверить регистрацию и режим локального хоста |

## Настройка AnimeJaNai

### Горячие клавиши

Привязки зависят от версии и пользовательской конфигурации; исходная настройка использовала AnimeJaNai 3.7.0.

| Сочетание | Действие |
|---|---|
| `Shift+1` / `Shift+2` / `Shift+3` | Quality / Balanced / Performance |
| `Ctrl+J` | Статистика: активный профиль и обработка |
| `Ctrl+E` | AnimeJaNai Manager, в том числе профиль по умолчанию |
| `Ctrl+U` | Обновление AnimeJaNai |
| `Ctrl+F` | Папка конфигурации: Settings → Open Config Folder |
| `Space` | Воспроизведение / пауза |
| `Enter` или `F` | Полноэкранный режим |
| `Q` | Закрытие плеера |
| `Стрелка вниз` | Перемотка вперед на 1:30 вперед |

Чтобы **Esc выходил из полного экрана, не закрывая плеер**, добавьте пользовательские привязки:

```conf
SPACE cycle pause
ESC set fullscreen no
```

В сборках с пользовательским файлом используйте `input-user.conf`, как описано в [документации AnimeJaNai](https://github.com/the-database/mpv-AnimeJaNai#customizing-profiles-and-other-settings). Если ваша сборка использует управляемый блок в `input.conf`, добавляйте строки после `#@ANIMEJANAI-MANAGED-END`. Не редактируйте содержимое блока `#@ANIMEJANAI-MANAGED-BEGIN` … `#@ANIMEJANAI-MANAGED-END`. Сохраните файл и перезапустите плеер.

### Кэш HLS

Необязательные настройки для предварительной загрузки видео. В поддерживающих его сборках добавьте в `mpv-user.conf` в папке конфигурации:

```conf
cache=yes
cache-secs=900
demuxer-max-bytes=768MiB
demuxer-max-back-bytes=64MiB
cache-pause=yes
```

Целевой запас — до 15 минут, но фактическая длительность ограничена также лимитом 768 MiB, битрейтом и доступностью данных. Это не гарантия загрузки всей серии. Параметры описаны в [руководстве mpv](https://mpv.io/manual/stable/). Менять аппаратное декодирование (`hwdec`) для работы расширения не требуется.

## Обновление и удаление

**Обновление:** закройте запущенные через расширение сеансы mpvnet, обновите файлы проекта, выполните `native\Build.ps1`, затем `install.cmd` и нажмите ↻ у расширения в `chrome://extensions`. Явная сборка нужна, чтобы оставшийся от предыдущей версии `.exe` не использовался повторно. На каждом ПК обновляйте оба компонента. После обновления перезапустите видео на сайте.

**Удаление:** выполните `uninstall.cmd`, затем удалите расширение в `chrome://extensions`. Скрипт снимает регистрацию и удаляет файлы локального хоста. AnimeJaNai и папка проекта сохраняются. При неизвестных файлах или чужой регистрации автоматическое удаление прекращается.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Поток не найден | Сайт сохранён, доступ разрешён, видео запускалось после установки или обновления расширения. Плеер должен быть поддерживаемым |
| `Specified native messaging host not found` | Запустите `install.cmd` под тем же пользователем Windows, что и Chrome |
| Доступ к хосту запрещён | Повторите установку с ID из `chrome://extensions` |
| `Registration belongs to another layout` при кириллице в пути профиля | Обновите файлы проекта и повторите `install.cmd`: исправлено чтение UTF-8 JSON в Windows PowerShell. Удалять регистрацию вручную и переименовывать профиль не нужно. Если ошибка остаётся, проверьте путь манифеста в регистрации хоста |
| Не найден плеер | Укажите фактический путь к `mpvnet.exe` при установке |
| `DryRun` или отказ старого списка доменов | Обновите оба компонента и повторите обычную установку |
| Повторный запуск отклонён | Подождите 10 секунд |
| Позиция не вернулась | Оставьте исходное видео на паузе, не меняйте страницу и файл в mpv; откройте расширение для сообщения о синхронизации |

Успешный ответ хоста означает создание процесса, а не готовность видео. Точность перемотки зависит от HLS и плеера. Потоки, требующие cookies или специальных заголовков, могут не воспроизводиться.

## Разрешения и приватность

Расширение запрашивает доступ к `https://*/*`, чтобы обнаруживать неизвестные заранее iframe и CDN. Обработчик сохраняет ссылки только для настроенных доменов вкладок, вне инкогнито. Локальный хост вызывается при запуске потока или проверке подключения.

Плеер распознаётся по домену `kodikplayer.com` или маршрутам `/serial/` и `/video/`; инициатор запроса должен совпадать с origin кадра. Это эвристика: она не доказывает, что найденный поток — нужная серия, и не исключает рекламу полностью.

Ссылки хранятся в `storage.session` до навигации или закрытия вкладки, максимум шесть часов. Cookies и авторизационные заголовки не копируются, аналитики и сетевых диагностических трасс нет. URL передаётся плееру в командной строке и может быть виден локальным процессам или попасть в собственные логи плеера.

Хост принимает команды только от зарегистрированного расширения и проверяет URL и время. Допускаются HTTPS HLS-ссылки без учётных данных, нестандартных портов, IP-литералов и очевидных локальных доменов. Это не сетевая изоляция: DNS, перенаправления и содержимое плейлиста обрабатывает mpv. Возврат позиции использует локальный именованный канал Windows.

## Разработка и проверки

- `extension/` — расширение Manifest V3.
- `native/` — C#-хост и установочные скрипты PowerShell.
- `tests/` — проверки фильтров, протокола, запуска и передачи позиции.

Сборка хоста из PowerShell:

```powershell
.\native\Build.ps1
```

Запуск тестов (дополнительно нужен Node.js 18+):

```powershell
.\tests\Run.ps1
```

Тесты используют отдельный тестовый плеер, не запускают AnimeJaNai и не воспроизводят реальные потоки. Проверяются валидация, изоляция вкладок, пауза и время, ограничение повторных запусков, возврат позиции и отказ при смене видео.

Ручная проверка интеграции: передайте видео в mpvnet, посмотрите ещё 20–30 секунд и закройте окно. Проверьте позицию и паузу в браузере; отдельно — сохранение позиции сайтом после перезагрузки. Автоматические тесты не заменяют эту проверку.

Для проверки установки без запуска плеера:

```powershell
.\native\Install-AnimeGo.ps1 -ExtensionId 'ВАШ_ID' -DryRun
```

Сгенерированные `.exe`, рабочая папка `work/` и архивы исключены через `.gitignore`. Для публикации исходников они не нужны.
