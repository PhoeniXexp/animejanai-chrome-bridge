# AnimeJaNai Chrome Bridge

Расширение Chrome для просмотра HLS / DASH-видео с настроенных сайтов в AnimeJaNai на Windows. Передаёт видео в плеер с текущей позиции минус 5 секунд и возвращает позицию в браузер после закрытия плеера.

## Установка

### 1. Скачать плеер

Скачайте и установите AnimeJaNai из [официальных релизов](https://github.com/the-database/mpv-AnimeJaNai/releases). Запустите `mpvnet.exe` и проверьте, что плеер работает.

### 2. Настроить хоткеи и кэш

Откройте папку настроек плеера: **Settings → Open Config Folder** (`Ctrl+F`).

В `input-user.conf` добавьте паузу на пробел и выход из полного экрана на Esc:

```conf
SPACE cycle pause
ESC set fullscreen no
```

Если сборка использует `input.conf` с управляемым блоком, добавляйте строки после `#@ANIMEJANAI-MANAGED-END`.

Для предварительной загрузки видео добавьте в `mpv-user.conf`:

```conf
cache=yes
cache-secs=900
demuxer-max-bytes=768MiB
demuxer-max-back-bytes=64MiB
cache-pause=yes
```

Кэш — до 15 минут в пределах 768 MiB; фактический запас зависит от битрейта и скорости загрузки. Сохраните файлы и перезапустите плеер.

Полезные клавиши (могут отличаться в разных версиях):

| Клавиши | Действие |
|---|---|
| `Shift+1` / `Shift+2` / `Shift+3` | Quality / Balanced / Performance |
| `Ctrl+J` | Статистика |
| `Ctrl+E` | AnimeJaNai Manager |
| `Ctrl+U` | Обновление плеера |
| `Enter` / `F` | Полный экран |
| `Q` | Закрыть плеер |

### 3. Установить расширение

1. Скачайте проект (**Code → Download ZIP**), распакуйте в постоянную папку.
2. Откройте `chrome://extensions`, включите **Режим разработчика** → **Загрузить распакованное расширение** и выберите папку `extension`.
3. Скопируйте ID расширения. Запустите `install.cmd` без прав администратора, введите ID и путь к `mpvnet.exe`. Enter оставляет предложенное значение; ID должен совпадать с вашим ID в Chrome.
4. В настройках расширения добавьте сайт, например `animego.online` или `animego.me` (несколько доменов — через пробел), нажмите **Сохранить** и разрешите доступ.
5. Нажмите **Проверить подключение к плееру**.

Обычный путь к плееру:

```text
%LOCALAPPDATA%\Programs\mpv-AnimeJaNai\mpvnet.exe
```

## Как пользоваться

1. Запустите нужную серию и озвучку на сайте.
2. В расширении нажмите **Открыть в плеере**. Видео в браузере встанет на паузу.
3. После просмотра закройте плеер — позиция вернётся в браузер, видео останется на паузе.

Для возврата позиции оставьте вкладку открытой, не меняйте серию и не возобновляйте видео в браузере.

## Обновление и удаление

**Обновление:** закройте плеер, обновите файлы проекта, выполните `native\Build.ps1` в PowerShell, затем `install.cmd`. Нажмите ↻ у расширения в `chrome://extensions` и перезапустите видео на сайте.

**Удаление:** запустите `uninstall.cmd` и удалите расширение из Chrome. Сам плеер сохраняется.

## Если не работает

- **Нет потока:** запустите серию и откройте меню расширения — расширение проверит и уже загруженные плейлисты. Если список пуст, проверьте разрешение для сайта, нажмите `Ctrl+Shift+R` на странице и снова запустите видео.
- **Нет подключения / доступ запрещён:** повторите `install.cmd` под тем же пользователем, что и Chrome, с правильным ID расширения и путём к плееру.
- **`Registration belongs to another layout` при кириллице в профиле:** обновите файлы проекта и повторите `install.cmd`.
- **Повторный запуск отклонён:** подождите 10 секунд.

Плееры определяются по наличию видео на странице или в iframe, без списка названий и доменов. Поддерживаются плейлисты `.m3u8` и `.mpd`. Если найдено несколько потоков, выберите нужный — среди них может быть реклама. При нескольких видимых видео в одном кадре запуск отменяется: расширение не угадывает позицию. DRM и потоки с обязательными cookies или специальными заголовками могут не воспроизводиться.

### Проверка потока через терминал

В Chrome откройте **F12 → Network**, запустите серию и найдите запрос `.mpd` или `.m3u8`. Скопируйте **Headers → Request URL** целиком, включая параметры после `?`. Файлы `.m4s` и `.ts` — отдельные части видео, нужен адрес плейлиста.

Откройте **PowerShell** и выполните:

```powershell
$playerDir = Join-Path $env:LOCALAPPDATA 'Programs\mpv-AnimeJaNai'
$stream = Read-Host 'Вставьте полный URL плейлиста'
$log = Join-Path $env:TEMP 'animejanai-stream.log'
& "$playerDir\mpvnet.exe" --process-instance=multi "--log-file=$log" -- "$stream"
```

Если плеер установлен в другом месте, замените `$playerDir`. Лог появится в `%TEMP%\animejanai-stream.log`.

Для проверки самого потока без настроек и апскейла AnimeJaNai закройте тестовое окно плеера и в том же PowerShell выполните:

```powershell
& "$playerDir\mpv.com" --no-config "--log-file=$log" -- "$stream"
```

Если второй вариант работает, а первый зависает, проверяйте настройки и апскейл плеера. Если не работают оба, скопируйте свежую ссылку: адрес потока может истечь или требовать заголовки/cookies. При таком запуске расширение не ставит браузер на паузу и не возвращает позицию просмотра.
